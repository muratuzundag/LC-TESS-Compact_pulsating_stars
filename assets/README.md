# Artwork

- `LC_TESS_banner.png`: 2200 x 760 pixels, pure black background; the README banner.
- `LC_TESS_emblem.png`: 720 x 720 pixels, pure black background; square emblem.
- `LC_TESS_banner.svg`: editable vector text/background with embedded raster emblem;
  it is a hybrid SVG, not an entirely vector reconstruction of the sphere.

The red–white–blue sphere was cropped from the owner's supplied `l1m1_mode.jpg`.
The original notebook frame/title is intentionally omitted from the logo.
The supplied `lc_animation_fast.jpg` is uniformly white and contributes no visible
curve. The cyan waveform/orbit and colored nodes are newly drawn decorative
motifs, not observations, fitted results, or a physical representation of a
particular mode's integrated light variation. No numerical claims are based on them.
