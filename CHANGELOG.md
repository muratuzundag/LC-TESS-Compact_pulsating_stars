# Changelog

## 0.1.0 — release candidate

- SPOC 20-s USC and 120-s SC light-curve retrieval by TIC or unambiguous coordinates.
- Per-sector normalization, amplitude periodograms and optional cadence-separated stitching.
- Optional matching-TPF localization of selected same-source frequencies.
- JSON provenance/error reporting, tests and GitHub Actions.
- Black-background emblem and banner based on supplied pulsation sphere.
- User documentation, clean tutorial notebook, license and citation metadata.

This snapshot is not a claim of live archive validation or an archived DOI release.
